# Changelog — NSE Sector Rotation App

---

## v2.4.8 (2026-02-22)

### New Features

1. **Dynamic N sectors in gates** (replaces fixed "Top 4 + Bottom 6" radio)
   - Bullish gate: slider to select top N sectors (1–4, default 1) by Momentum Ranking.
   - Bearish gate: slider to select bottom N sectors (1–6, default 2) by Momentum Ranking.
   - Sector filter logic is now fully driven by the gate enabled/disabled state.

2. **Wider date range in Stock Screener** (10 → 30 days) with navigation buttons
   - Date dropdown now shows up to 30 past trading days.
   - ◀ Previous day / Next day ▶ buttons below the dropdown for single-day navigation.

3. **Forward return columns in bull/bear tables**
   - `1D%`, `2D%`, `3D%`, `1W%` columns added to both Bullish and Bearish results tables.
   - Shown as `+/-` formatted values; blank when future data is not yet available (last 5 trading days).
   - Daily data is fetched without end-date cap; analysis-date slice used for all indicators; full dataset used for return computation.

4. **Gate defaults updated**
   - Both Bullish and Bearish master gates: **enabled by default**.
   - MA8 (1H), VWAP (1H), RSI exclusions: all **unchecked by default**.
   - RSI threshold now gated by an explicit checkbox (default OFF) — slider present but inactive unless ticked.

5. **Downloadable changelog**
   - `CHANGELOG_v248.md` added to project root.
   - Download button available in sidebar under "📥 Download Changelog".

6. **Win rate denominator fix**
   - `_win_rate_table` now pre-filters to rows where the 1W return is non-null.
   - Entries in the last 5 trading days (no 1W data yet) are excluded from all win rate calculations.

7. **Composite win rate metric**
   - New `🎯 Composite Win Rate` section in Historical Rankings.
   - Combines bullish performance on green days with bearish performance on red days into one combined metric.
   - Only counts days with 1W return available.

8. **Centralised confluence toggle**
   - "Enable Confluence Analysis" toggle moved to the **Confluence_Future** tab.
   - Timeframe selector (1D+2H / 4H+1H) also lives in Confluence_Future tab.
   - Stock Screener (PART 3) and Historical Rankings read enabled state from `session_state["_confluence_enabled"]`.
   - Both tabs show a guide message directing users to Confluence_Future when OFF.

## v2.4.7 (2026-02-15)

### Bug Fixes & Improvements

1. **Decimal display fix** — Bull/bear tables in Stock Screener now format Price (1 dp), RSI (0 dp), and Score (1 dp) correctly using `.format()` with `na_rep=''`.

2. **Removed "Confluence pertains" text** — Replaced generic Confluence messaging in Sector Selection info boxes with specific "Momentum Ranking selects top N bullish / bottom N bearish sectors" copy.

3. **Hide PART 3 heading when confluence OFF** — Stock Screener PART 3 section heading only renders after the confluence toggle is ON; disabled state shows a neutral info message.

4. **Sector sync via session_state** — Stock Screener saves `_screener_top4` / `_screener_bot6` to `session_state`; Historical Rankings reads from that state so both tabs reflect the same sectors without re-computing.

5. **Snapshot time sync** — Stock Screener saves the selected snapshot hour to `session_state["_screener_snap_h"]`; Historical Rankings uses this value for consistent 1H indicator computations.

6. **Sector caption in Historical Rankings** — Added an info line showing which sectors were used for the bullish/bearish picks on the displayed date.
