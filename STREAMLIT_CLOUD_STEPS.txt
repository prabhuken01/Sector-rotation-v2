═══════════════════════════════════════════════════════════════
  DEPLOY TO STREAMLIT CLOUD - STEP BY STEP
═══════════════════════════════════════════════════════════════

IMPORTANT: You DON'T need Codespaces! Streamlit Cloud deploys
directly from your GitHub repository.

═══════════════════════════════════════════════════════════════
STEP 1: COMMIT YOUR CHANGES
═══════════════════════════════════════════════════════════════

Run these commands in your terminal:

  git add .
  git commit -m "Add Top 2 Best Stocks tab and ETF default"
  git push origin main

═══════════════════════════════════════════════════════════════
STEP 2: GO TO STREAMLIT CLOUD
═══════════════════════════════════════════════════════════════

1. Open your browser
2. Go to: https://streamlit.io/cloud
3. Click "Sign in" button
4. Authorize with your GitHub account

═══════════════════════════════════════════════════════════════
STEP 3: CREATE NEW APP
═══════════════════════════════════════════════════════════════

1. Click the "New app" button (top right)
2. In the dropdown:
   - Repository: Select "prabhuken01/Sector-rotation-v2"
   - Branch: Select "main"
   - Main file path: Type "streamlit_app.py"
3. Click "Deploy" button

═══════════════════════════════════════════════════════════════
STEP 4: WAIT FOR DEPLOYMENT
═══════════════════════════════════════════════════════════════

- Build takes 2-5 minutes
- You'll see progress in the dashboard
- When done, you'll get a URL like:
  https://[your-app-name].streamlit.app

═══════════════════════════════════════════════════════════════
WHAT HAPPENS BEHIND THE SCENES
═══════════════════════════════════════════════════════════════

1. Streamlit Cloud reads your GitHub repo
2. Installs packages from requirements.txt
3. Runs: streamlit run streamlit_app.py
4. Gives you a live URL

NO CODESPACES INVOLVED!

═══════════════════════════════════════════════════════════════
TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

If build fails:
- Check the "Logs" tab in Streamlit Cloud
- Verify requirements.txt has all packages
- Make sure streamlit_app.py exists

If app crashes:
- Check "Logs" tab for errors
- Verify all Python files are in repo

═══════════════════════════════════════════════════════════════
YOUR APP WILL BE LIVE AT:
═══════════════════════════════════════════════════════════════

https://[your-app-name].streamlit.app

Share this URL with anyone!
